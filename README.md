# 📋 Gerenciador de Tarefas

Aplicação web para gerenciamento de tarefas desenvolvida para organizar atividades diárias de forma simples e intuitiva. O sistema permite criar, editar, concluir e remover tarefas através de uma interface prática e responsiva.

## 🚀 Demonstração

🔗 [(https://gerenciador-de-tarefas-liart.vercel.app](https://gerenciador-de-tarefas-liart.vercel.app/)

---

## ✨ Funcionalidades

- ✅ Criar tarefas
- ✏️ Editar tarefas existentes
- 🗑️ Remover tarefas
- ✔️ Marcar tarefas como concluídas
- 📱 Layout responsivo
- 💾 Persistência de dados
